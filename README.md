# 🧠 Autism Detection in Children using YOLOv8

This project leverages **YOLOv8**, a cutting-edge object detection model, to identify children showing visible behavioral signs associated with autism spectrum disorder (ASD) from images and videos. The aim is to assist early screening and support efforts using AI-based visual analysis.

---

## 🚀 Project Overview

- **Objective**: Detect and localize children with potential signs of autism using visual cues captured in various scenarios (e.g., eye contact, facial expression, body language).
- **Model Used**: [YOLOv8](https://github.com/ultralytics/ultralytics) (You Only Look Once - version 8)
- **Framework**: Python, PyTorch, Ultralytics

---

## 📁 Dataset

Due to ethical and privacy concerns, datasets used in this project are not publicly shared. However, a custom dataset was collected and annotated for:
- Children with suspected autism
- Children without autism (as control)

Annotations were created in YOLO format using tools like  [Roboflow](https://roboflow.com/).
